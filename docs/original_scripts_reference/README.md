# Generalized original scripts

These are the supplied reference scripts with purpose-based filenames.
Personal computer paths, usernames, thesis-directory names, and
study-specific place names have been removed.
The analysis steps and package choices are otherwise retained as closely as
possible.

## Input and output conventions

Replace the representative paths below with files available in your own
project:

- `data/*.csv` for CSV input tables
- `data/*.xlsx` for Excel input tables
- `data/study_area_boundary.shp` for a study-area boundary
- `data/land_use_raster.tif` for a land-use raster
- `outputs/` for generated tables, figures, and reports

The scripts are reference material and may still contain different expected
column names, experimental designs, or package requirements. Inspect the
data import and model settings before running a script. The cleaned,
maintained versions for routine use are in the repository's `R/` directory.
